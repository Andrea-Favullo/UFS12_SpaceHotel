# Descrizione
Navicella navigabile in VR realizzata in Unreal Engine 4.27 realizzata da Andrea Favullo (programmatore e modellatore), Sara Mangialardi e Hamdy Khedr (modellatori).<br>
L'utente può:
<ol>
  <li>
    Cambiare il materiale di alcuni oggetti nel livello. 
  </li>
  <li>
    Visualizzare un menu di descrizione del livello. 
  </li>
  <li>
    Aprire la porta alla sala relax. 
  </li>
</ol>

# Installazione
<ol>
  <li>
    Scaricare la versione Unreal Engine 4.27.2.
  </li>
  <li>
    Clonare il repo all'interno di una cartella.
  </li>
  <li>
    Aprire il progetto da Unreal Engine selezionando il percorso del progetto <b>oppure</b> eseguire il file <i>SpaceHotel.uproject</i>.
  </li>
</ol>
